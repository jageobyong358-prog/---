# 합(合) 전투 시뮬레이터

림버스 컴퍼니식 전투 규칙(합 · 코인 · 피해량 · 내성 · 죄악 속성 · 공격/방어 레벨)으로 동작하는 웹 전투 시뮬레이터입니다.
키워드 · 패시브는 자연어로 설명하면 **AI(Claude)가 실제 동작하는 코드로 구현**하고, 스킬 VFX도 AI가 만듭니다.

- 계정 없이 바로 플레이, 만든 콘텐츠는 이 기기의 브라우저(IndexedDB)에 저장
- 캐릭터 / 스킬 이미지 업로드
- **합 진행 메시지**: 문구와 색을 고르면 화려하게 흔들리는 텍스트 이펙트로 출력 (스킬 사용 / 합 시작 / 합 승리 / 합 패배 / 처치 / 흐트러짐 유발 시점)
- **VFX AI**: 전투 시작 시 VFX가 없는 스킬의 연출을 AI가 자동 생성 (스킬 편집에서 직접 요청/미리보기도 가능)
- **관리자 콘텐츠 AI**: 관리자 탭에서 관리자 코드를 입력하면 테스트 서버에서 웹 속 AI에게 신규 캐릭터·스킬·키워드를 요청하고, 검증 후 라이브에 배포(`content/live.json`)
- **전투 영상 다운로드**: "전투를 영상으로 녹화"를 켜거나 전투 중 `● 녹화`를 누르면, 전투가 끝난 뒤 MP4(브라우저에 따라 WebM)로 내려받을 수 있음

빌드 과정이 없는 정적 웹앱입니다 (ES 모듈). 아무 정적 호스팅(GitHub Pages 등)에 올리면 됩니다.

## 실행

```bash
python3 -m http.server 8080   # 아무 정적 서버
# http://localhost:8080        라이브 서버
# http://localhost:8080/?server=test  테스트 서버
```


## 전투 규칙 (구현 내용)

| 항목 | 내용 |
|---|---|
| 스킬 위력 | 기본 위력 + 앞면 코인 수 × 코인 위력 (마이너스 코인 지원) |
| 코인 | 앞면 확률 = 50% + 정신력(SP, −45~45)% |
| 합 | 서로 위력을 굴려 진 쪽이 코인 1개 파괴, 한쪽 코인이 0이 될 때까지 반복. 공격 레벨이 3 높을 때마다 합 위력 +1 |
| 공격 | 합 승리 시 남은 코인을 다시 던져 코인마다 누적 위력으로 타격 |
| 피해 배율 | 1 + (물리 내성−1) + (죄악 내성−1) + (공격Lv−방어Lv)/(\|차이\|+25) + 합 횟수×3%(최대 30%) + 치명타 20% + 기타 |
| 내성 | 치명 ×2.0 / 취약 ×1.5 / 보통 ×1.0 / 견딤 ×0.5 / 내성 ×0.25 |
| 흐트러짐 | 체력이 역치 아래로 떨어지면 흐트러짐(+/++), 다음 턴 종료까지 행동 불가, 물리 내성 치명 |
| 속도 | 매 턴 속도 주사위. 빠른 유닛이 공격하면 느린 대상의 공격을 끌어와 합 |
| 수비 스킬 | 수비(패배해도 위력만큼 피해 흡수) / 회피 / 반격 |
| 스킬 덱 | 스킬1 ×3, 스킬2 ×2, 스킬3 ×1 덱에서 매 턴 2장 제시 + 수비 스킬 |
| SP | 합 승리 +10, 처치 +10, 아군 사망 −10 |
| 내장 키워드 | 화상, 출혈, 진동(폭발), 파열, 침잠, 호흡, 충전, 보호, 취약, 피해량 증감, 신속, 속박, 공격/방어 레벨 증감, 위력 증감, 마비 |

간소화한 부분: 공명/E.G.O 는 구현하지 않았고 죄악 자원만 집계합니다. 정확한 원작 수치가 다른 부분은 `js/engine/engine.js` 상단 상수에서 조정할 수 있습니다.

## AI 키워드 / 패시브

키워드·패시브 탭에서 효과를 자연어로 적고 **✦ AI로 구현**을 누르면, AI가 전투 엔진의 훅(`onTurnEnd`, `beforeHit`, `onClashWin` …)에 맞는 JavaScript를 작성하고, 샌드박스에서 컴파일 검증(실패 시 자동 1회 수정)까지 합니다. 저장하면 스킬 효과나 캐릭터 패시브에서 바로 쓸 수 있습니다.

**보안**: 사용자/AI가 만든 코드는 페이지와 분리된 `sandbox="allow-scripts"` iframe(불투명 origin, 네트워크 차단 CSP) 안의 전투 엔진에서만 실행됩니다. 로그인 정보·저장소·DOM 에 접근할 수 없습니다.

## 설정 (`js/config.js`)

- **`anthropicApiKey`**: 사이트 공용 Anthropic API 키(`sk-ant-…`). 넣으면 모든 방문자가 바로 AI 기능을 씁니다.
  ⚠ 정적 사이트라 **방문자 누구나 이 키를 볼 수 있습니다.** 이 사이트 전용 키를 따로 만들고 Anthropic 콘솔에서 월 사용 한도를 걸어 두세요. 비워 두면 각 사용자가 **설정** 탭에 자기 키를 넣습니다(그 브라우저에만 저장).
- **`adminPasswordHash`**: 관리자 코드의 SHA-256 해시(설정되어 있음). 관리자 탭에서 코드를 입력하면 그 브라우저에서 관리자 기능이 켜집니다. 코드를 바꾸려면 새 코드의 SHA-256 해시로 교체하세요 (`printf '새코드' | sha256sum`).
- **`model`**: 사용할 Claude 모델 (기본 `claude-opus-5-5`). 거절 응답 대비 서버측 fallback(`fallbacks: "default"`)을 켜 두었습니다.

## 서버 구조

- **라이브**: 저장소의 `content/live.json` — 모든 방문자에게 적용
- **테스트**: `?server=test` 로 접속, 관리자가 이 기기에서 만든 콘텐츠(IndexedDB)를 라이브 위에 얹어 테스트
- **개인**: 각 방문자가 만든 콘텐츠 (각자의 브라우저)

관리자 흐름: 관리자 탭 → 관리자 코드 입력 → 테스트 서버로 이동 → AI 에게 "출혈을 쌓다 터뜨리는 키워드와 그걸 쓰는 캐릭터를 만들어줘" 같이 요청 → 결과 확인 → 테스트 서버에 추가 → 전투로 테스트 → **라이브 배포** → **live.json 내보내기** → 받은 파일을 `content/live.json` 에 덮어쓰고 커밋·배포.

## 전투 영상

화면 녹화(`getDisplayMedia` + `MediaRecorder`)로 전투 영역을 그대로 녹화하므로 VFX와 메시지 이펙트가 모두 담깁니다. 브라우저가 녹화할 탭을 물으면 **이 탭**을 선택하세요. PC용 Chrome / Edge 에서 가장 잘 동작하며(전투 영역만 잘라서 녹화), 모바일 브라우저는 화면 녹화를 지원하지 않습니다.

```
index.html, css/style.css
js/engine/engine.js   전투 엔진 (샌드박스 안에서 실행)

js/defaults.js        기본 캐릭터·스킬·패시브 (오리지널)

js/recorder.js        전투 영상 녹화/다운로드
js/store.js           IndexedDB 저장, 관리자 비밀번호 확인, 설정
js/library.js         콘텐츠 병합 (기본 < 라이브 < 테스트 < 내 것)

js/ui/*.js            전투 / 편집기 / 관리자 화면
tests/engine.test.mjs 엔진 테스트 (node tests/engine.test.mjs)
```
